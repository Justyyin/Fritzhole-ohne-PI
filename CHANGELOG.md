# Changelog

All notable changes to this project are documented in this file.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2026-10-24

### Added

- Step-by-step guide in German (`README.md`) and English (`README.en.md`) for the DNS filter in FRITZ!OS 8.40 Lab and 8.50
- Annotated screenshots of the FRITZ!OS user interface (FRITZ!Box 6690 Cable)
- Chapter on the FRITZ!Box DNS configuration: local DNS server (IPv4, IPv6), upstream DNS with DNS over TLS, DNS rebind protection, checklist
- Filter list selection based on [hagezi/dns-blocklists](https://github.com/hagezi/dns-blocklists)
- Alternative setup with public filtering DNS (Mullvad, AdGuard) for models without a DNS filter
- Legal notes in German and English
- Test scripts for Linux/macOS and Windows, list validation script, allowlist template
- Issue templates
