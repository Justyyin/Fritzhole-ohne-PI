# Contributing / Mitwirken

## Deutsch

Beiträge sind willkommen, insbesondere:

- neue FRITZ!OS-Versionen oder geänderte Menüpfade
- Bestätigungen für weitere Modelle (Modell, FRITZ!OS-Version, verwendete Liste)
- Bildschirmfotos anderer Modelle oder der englischen Oberfläche
- Korrekturen mit Quellenangabe

Regeln:

1. Keine personenbezogenen oder gerätespezifischen Daten einreichen: keine `.export`-Dateien, keine IP- oder MAC-Adressen, Seriennummern, Telefonnummern oder WLAN-Namen. Bildschirmfotos vorher schwärzen.
2. Fakten mit Quelle belegen (Änderungsprotokoll, Online-Hilfe, Fachartikel).
3. Filterlisten nicht in das Repository kopieren, sondern verlinken.
4. Änderungen an `README.md` und `README.en.md` inhaltlich synchron halten.
5. `CHANGELOG.md` ergänzen.

Ablauf: Issue mit der passenden Vorlage eröffnen oder Fork, Branch und Pull Request.

## English

Contributions are welcome, in particular:

- new FRITZ!OS versions or changed menu paths
- confirmations for further models (model, FRITZ!OS version, list used)
- screenshots of other models or of the English user interface
- corrections with a source reference

Rules:

1. Do not submit personal or device-specific data: no `.export` files, IP or MAC addresses, serial numbers, phone numbers or Wi-Fi names. Redact screenshots beforehand.
2. Back up facts with a source (changelog, online help, trade articles).
3. Do not copy filter lists into the repository; link to them.
4. Keep `README.md` and `README.en.md` in sync.
5. Update `CHANGELOG.md`.

Process: open an issue using the matching template, or fork, branch and open a pull request.
